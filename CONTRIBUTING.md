# Cómo contribuir

¡Gracias por interesarte en OpenZenit!

- Explica claramente qué cambia tu contribución.
- Prueba el código antes de enviar cambios.
- Usa únicamente datos que tengas derecho a distribuir.
- No publiques claves API, contraseñas ni datos privados.
- Recuerda que este proyecto es experimental y educativo.
